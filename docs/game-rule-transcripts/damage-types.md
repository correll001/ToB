## B. 傷害類型（完整轉寫）

1. 任何一個傷害都必定屬於下列五種傷害類型之一：物理、火焰、冰冷、閃電、腐蝕。

2. 除了物理傷害以外，其餘的傷害類型受到對應抗性的影響。
