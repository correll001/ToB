## D. 抗性穿透（完整轉寫）

1. 抗性穿透在傷害計算過程中作用於防守方的有效抗性。

2. 若攻擊方擁有某種抗性穿透，則在計算傷害時，從防守方的對應抗性中減去相應的值。

3. 抗性穿透不改變防守方實際的抗性值。

4. 抗性穿透對任何傷害形式（擊中、持續、間接、反射）均生效。
